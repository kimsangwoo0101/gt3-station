GT3 작화 스테이션

도면 → 작화 JSON → GT Designer3
GT3 연결 서버 확인 전 GT Designer3 — 연결 키 —

1이 PC의 GT3 연결 서버

    GT Designer3가 깔린 PC에서 시작.bat을 켜 두세요.

    처음 쓰는 PC라면 — 연결 프로그램 받기
    1. plc-helper.zip 받기 → C:\Users\(내 이름)에 '모두 압축 풀기'
    2. 설치.bat 더블클릭 (보안 경고 창은 직접 '예') → 브라우저를 닫았다가 다시 열기
    3. GT Designer3를 켜고 시작.bat 더블클릭 → 검은 창에 나온 연결 키를 위 칸에 넣기

    Windows와 GT Designer3가 필요합니다. 설치 안내 자세히

    2도면 사진

    사진을 끌어다 놓거나, 눌러서 고르거나, Ctrl+V로 붙여 넣기

    사진은 이 브라우저 안에서만 쓰고 어디에도 올리지 않아요. 패널 테두리를 끌어서 지정하면 미리보기에 겹쳐 보여 줍니다.

    3작화 JSON

    작화 JSON 파일을 끌어다 놓거나 눌러서 고르기 (여러 개 가능)
    JSON 글을 직접 붙여 넣기

    작화 JSON이 없으면 [AI 요청 글 복사]를 눌러 Claude나 Copilot 채팅에 도면 사진과 함께 붙여 넣으세요. 받은 JSON을 여기에 넣으면 됩니다.
